  <behavior>
    - test_cooldown_allows_first_alert: CooldownTracker.check(rule_id=1) returns True on first call
    - test_cooldown_blocks_during_window: After check(rule_id=1) returns True, subsequent check(rule_id=1) returns False within default 5-minute window
    - test_cooldown_allows_after_expiry: After cooldown expires (mock time), check(rule_id=1) returns True again
    - test_cooldown_different_rules_independent: check(rule_id=1) does not affect check(rule_id=2)
    - test_cooldown_custom_window: CooldownTracker(default_seconds=60) uses 60s window
    - test_cooldown_suppressed_count: get_suppressed_count(rule_id=1) returns number of suppressed alerts since last firing
    - test_webhook_skipped_during_cooldown: _execute_webhook returns early with cooldown detail when blocked
  </behavior>
  <action>
    1. Create mqttui/rules/cooldown.py:
       - class CooldownTracker:
         - __init__(self, default_seconds=300): self._last_fired = {} (rule_id -> timestamp), self._suppressed = {} (rule_id -> count), self._default = default_seconds
         - check(self, rule_id: int, cooldown_seconds: int | None = None) -> bool:
           - If rule_id not in _last_fired or now - _last_fired[rule_id] > cooldown_seconds: record timestamp, reset suppressed count to 0, return True
           - Else: increment _suppressed[rule_id], return False
         - get_suppressed_count(self, rule_id: int) -> int: return _suppressed.get(rule_id, 0)
         - get_cooldown_until(self, rule_id: int, cooldown_seconds: int | None = None) -> datetime | None: return _last_fired + cooldown_seconds as datetime
       - Module-level singleton: cooldown_tracker = CooldownTracker()

    2. Integrate cooldown into mqttui/rules/actions.py _execute_webhook:
       - Before submitting to thread pool, call cooldown_tracker.check(context['rule_id'])
       - If blocked: create AlertHistory record with suppressed_count incremented, return {"success": True, "detail": "Alert suppressed (cooldown)"}
       - If allowed: proceed with delivery as before

    3. Write tests/test_cooldown.py with all behaviors listed above.
       - Use time.monotonic mocking for deterministic timing tests
  </action>
