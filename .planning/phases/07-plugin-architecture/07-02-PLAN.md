  <action>
    1. Create mqttui/plugins/runner.py:
       - Import subprocess, json, structlog, time
       - PLUGIN_TIMEOUT = 5 (seconds)
       - class PluginRunner:
         - __init__(self, app=None): store app ref, logger = structlog.get_logger(__name__)
         - call_plugin(self, plugin_config: PluginConfig, event_type: str, data: dict) -> list[dict]:
           - Build the subprocess command: `[sys.executable, "-m", plugin_config.entry_point]`
           - Build input JSON: json.dumps({"event": event_type, "data": data}) + "\n"
           - Use subprocess.Popen(cmd, stdin=PIPE, stdout=PIPE, stderr=PIPE, text=True, env={}) with EMPTY env dict (isolation -- no access to app env vars)
           - communicate(input=input_json, timeout=PLUGIN_TIMEOUT)
           - Parse stdout as JSON: expect {"actions": [...]} format
           - On timeout: proc.kill(), log warning, return []
           - On invalid JSON: log warning, return []
           - On any exception: log error, return []
           - Return list of action dicts
         - dispatch_message(self, topic: str, payload: str) -> list[dict]:
           - Get registry via get_plugin_registry()
           - For each enabled plugin from registry.get_enabled_plugins():
             - Call call_plugin(plugin, "on_message", {"topic": topic, "payload": payload})
             - Collect all returned actions
           - Return all actions
         - dispatch_actions(self, actions: list[dict]):
           - For each action in actions:
             - If action["type"] == "publish": import mqttui.mqtt_client, call publish(action["topic"], action["payload"])
             - If action["type"] == "log": log the action["message"] via structlog
             - Unknown types: log warning and skip
         - on_mqtt_message(self, sender, **kwargs):
           - Extract topic, payload from kwargs
           - payload_str = payload if isinstance(payload, str) else str(payload)
           - actions = dispatch_message(topic, payload_str)
           - dispatch_actions(actions)
       - Module-level singleton:
         - _runner = None
         - def get_plugin_runner() -> PluginRunner: return _runner
         - def init_plugin_runner(app) -> PluginRunner: create PluginRunner(app), assign to _runner, return it

       - Test invalid JSON: mock communicate to return non-JSON stdout

       - Test dispatch_actions with publish type: mock mqtt_client.publish, verify called
