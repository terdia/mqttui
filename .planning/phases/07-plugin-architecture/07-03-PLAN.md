       - GET /api/v1/plugins — @login_required, get_plugin_registry().list_plugins(), return api_success(plugins)
       - POST /api/v1/plugins/<name>/enable — @login_required, registry.enable(name), return api_success or api_error(404)
       - POST /api/v1/plugins/<name>/disable — @login_required, registry.disable(name), return api_success or api_error(404)
       - GET /partials/plugins — @login_required, render_template('partials/plugins.html', plugins=registry.list_plugins())

    4. Create mqttui/plugins/examples/json_formatter.py:
       - This is a standalone script that reads JSON from stdin and writes JSON to stdout
       - #!/usr/bin/env python3
       - import sys, json
       - Read one line from stdin, parse as JSON
       - Extract event data: if event == "on_message", try json.loads(data["payload"]), pretty-print with json.dumps(indent=2)
       - Output: {"actions": [{"type": "transform", "result": pretty_printed_string}]}
       - If payload is not valid JSON: {"actions": []}
       - Wrap in try/except, handle errors gracefully

    5. Create mqttui/plugins/examples/topic_logger.py:
       - Standalone script: reads JSON from stdin, writes JSON to stdout
       - If event == "on_message": log topic and payload to stderr (since stdout is for protocol)
       - Output: {"actions": [{"type": "log", "message": "Topic: {topic}, Payload: {payload}"}]}
