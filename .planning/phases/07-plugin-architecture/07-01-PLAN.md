    1. Add `pluggy>=1.5.0` to requirements.txt (after prometheus_client line).

    2. Create mqttui/plugins/__init__.py -- empty init file for package.

    3. Create mqttui/plugins/hookspec.py:
       - Import pluggy
       - Define PROJECT_NAME = "mqttui"
       - Define hookspec = pluggy.HookspecMarker(PROJECT_NAME)
       - Define hookimpl = pluggy.HookimplMarker(PROJECT_NAME)
       - Create class MQTTUIPlugin:
         - @hookspec: def on_message(self, topic: str, payload: str) -> dict | None
         - @hookspec: def on_connect(self) -> None
         - @hookspec: def on_rule_trigger(self, rule_name: str, topic: str, payload: str) -> dict | None
       - NOTE: These are hookspec definitions, NOT abstract methods. pluggy uses marker decorators.

    4. Create mqttui/plugins/models.py:
       - Import sa from mqttui.extensions
       - class PluginConfig(sa.Model):
         - __tablename__ = 'plugin_configs'
         - id: Integer, primary_key
         - name: String(200), unique, nullable=False
         - entry_point: String(500), nullable=False
         - enabled: Boolean, default=False (plugins start disabled)
         - config_json: Text, default='{}'
         - version: String(50), nullable=True
         - description: Text, nullable=True
         - installed_at: DateTime, server_default=sa.func.now()
         - def to_dict(self): return dict with all fields

    5. Create mqttui/plugins/registry.py:
       - Import importlib.metadata, pluggy, structlog
       - Import MQTTUIPlugin, hookspec markers from hookspec.py
       - Import PluginConfig from models.py
       - Import sa from mqttui.extensions
       - class PluginRegistry:
         - __init__(self, app=None): store app ref, create pluggy.PluginManager(PROJECT_NAME), add_hookspecs(MQTTUIPlugin)
         - discover(self) -> list[dict]: Use importlib.metadata.entry_points(group='mqttui.plugins'), for each entry point load metadata (name, version), upsert PluginConfig row if not exists. Return list of discovered plugin dicts.
         - list_plugins(self) -> list[dict]: Query all PluginConfig rows, return as list of to_dict().
         - get_enabled_plugins(self) -> list[PluginConfig]: Query PluginConfig.query.filter_by(enabled=True).all()
         - enable(self, name: str) -> bool: Find PluginConfig by name, set enabled=True, sa.session.commit(), return True. Return False if not found.
         - disable(self, name: str) -> bool: Find PluginConfig by name, set enabled=False, sa.session.commit(), return True. Return False if not found.
       - Module-level singleton: _registry = None
       - def get_plugin_registry() -> PluginRegistry: return _registry
       - def init_plugin_registry(app) -> PluginRegistry: create PluginRegistry(app), assign to _registry, call discover(), return _registry

    6. Create tests/test_plugin_registry.py:
       - Use existing app/client fixtures from conftest.py
       - Test MQTTUIPlugin hookspec has expected methods
       - Test PluginConfig model CRUD (create, query, update enabled)
       - Test PluginRegistry.discover() with mocked entry_points (patch importlib.metadata.entry_points to return empty or mock entries)
       - Test enable/disable toggle PluginConfig.enabled
       - Test list_plugins returns correct dicts
       - Test get_enabled_plugins filters correctly
