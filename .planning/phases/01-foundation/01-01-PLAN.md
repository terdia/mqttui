**mqttui/app.py** — the factory:
```python
def create_app(config=None):
```
Inside create_app:
1. Create Flask instance: `app = Flask(__name__, static_folder='../static', template_folder='../templates')` (templates/static stay at project root for now)
2. Load config from env vars (same keys as current app.py: SECRET_KEY, DEBUG, HOST, PORT, MQTT_*, DB_*)
3. If config dict passed, override with `app.config.update(config)`
4. Initialize SocketIO with `async_mode='gevent'`: `socketio.init_app(app, async_mode='gevent')`
5. Initialize database if DB_ENABLED:
   ```python
   from mqttui.database import MessageDatabase
   global db
   db_instance = MessageDatabase(app.config['DB_PATH'], app.config['DB_MAX_MESSAGES'])
   import mqttui.extensions as ext
   ext.db = db_instance
   ```
6. Register blueprints:
   ```python
   from mqttui.routes.main import bp as main_bp
   from mqttui.routes.api import bp as api_bp
   from mqttui.routes.debug import bp as debug_bp
   app.register_blueprint(main_bp)
   app.register_blueprint(api_bp)
   app.register_blueprint(debug_bp)
   ```
7. Set up logging (same rotating file handler logic from current app.py)
8. Return app

**mqttui/database.py:**
Copy database.py into package. Add WAL mode and busy_timeout to get_connection():
```python
def get_connection(self):
    if not hasattr(self._local, 'connection'):
        self._local.connection = sqlite3.connect(
            self.db_path,
            check_same_thread=False,
            timeout=30.0
        )
        self._local.connection.row_factory = sqlite3.Row
        # Enable WAL mode for concurrent read/write
        self._local.connection.execute('PRAGMA journal_mode=WAL')
        self._local.connection.execute('PRAGMA busy_timeout=5000')
        # Add REGEXP function
        self._local.connection.create_function("REGEXP", 2, self._regexp)
    return self._local.connection
```
