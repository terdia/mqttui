    - Test 4: Expired timestamps outside window are not counted in rate
    - Test 5: Numeric JSON payload (e.g., '{"temperature": 22.5}') updates histogram stats (min, max, sum, count)
    - Test 6: Non-numeric or non-JSON payloads do not crash histogram tracking (graceful skip)
    - Test 7: get_topic_stats() returns dict with rate and histogram data per topic
    - Test 8: get_all_stats() returns list of all topics sorted by message rate descending
  </behavior>
  <action>
Create mqttui/analytics.py with a TopicAnalytics class:

1. **Data structures per topic:**
   - `_timestamps`: dict[str, deque] — rolling window of message timestamps (maxlen=10000)
   - `_histograms`: dict[str, dict] — per-topic numeric stats: {min, max, sum, count} for each numeric JSON field

2. **record(topic, payload, timestamp):**
   - Append timestamp to _timestamps[topic] deque
   - Try json.loads(payload), walk top-level keys, if value is int/float, update _histograms[topic][field_name] with min/max/sum/count

3. **get_rate(topic, window=60):**
   - Count entries in _timestamps[topic] within last `window` seconds using time.monotonic or datetime comparison
   - Return float (messages per window)

4. **get_topic_stats(topic):**
   - Return {"topic": topic, "rate_per_min": get_rate(topic, 60), "rate_per_hour": get_rate(topic, 3600), "message_count": len(deque), "histograms": _histograms.get(topic, {})}

5. **get_all_stats(limit=20):**
   - Return list of get_topic_stats() for all topics, sorted by rate_per_min descending, limited to top N

6. **Module-level singleton pattern** (same as CooldownTracker in Phase 4):
   ```python
   _analytics = None
   def get_analytics():
       global _analytics
       if _analytics is None:
           _analytics = TopicAnalytics()
       return _analytics
   ```

7. **Signal subscriber** — module-level function:
   ```python
   def _on_mqtt_message(sender, **kwargs):
       get_analytics().record(kwargs['topic'], kwargs['payload'], kwargs['timestamp'])
   ```

Do NOT use threading locks — gevent greenlets are cooperative. Use collections.deque(maxlen=10000) for automatic memory bounding.
