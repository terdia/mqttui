  <action>
    Create `mqttui/routes/rules.py`:

    ```python
    from flask import Blueprint, request
    from flask_login import login_required
    import json
    import logging

    from mqttui.extensions import sa
    from mqttui.helpers import api_success, api_error
    from mqttui.rules.models import Rule
    from mqttui.rules.evaluator import evaluate, ConditionError
    from mqttui.events import rule_changed

    rules_bp = Blueprint('rules', __name__, url_prefix='/api/v1/rules')
    logger = logging.getLogger(__name__)
    ```

    Endpoints:

    1. **GET /api/v1/rules** (`@rules_bp.route('/')`)
       - `@login_required`
       - Query Rule.query.order_by(Rule.created_at.desc()).all()
       - Return api_success({"rules": [r.to_dict() for r in rules]})

    2. **POST /api/v1/rules** (`@rules_bp.route('/', methods=['POST'])`)
       - `@login_required`
       - Validate: name (required, string), trigger_topic (required, string), action (required, dict with 'type' key)
       - Optional: description, condition (dict), rate_limit_per_min (int, default 10), schedule_cron (string), enabled (bool, default True)
       - Create Rule: condition_json=json.dumps(data.get('condition', {})), action_json=json.dumps(data['action'])
       - sa.session.add(rule); sa.session.commit()
       - rule_changed.send('api', action='created', rule_id=rule.id)
       - Return api_success(rule.to_dict(), 201)

    3. **GET /api/v1/rules/<int:rule_id>**
       - `@login_required`
       - Rule.query.get_or_404(rule_id) — catch 404 manually: `rule = Rule.query.get(rule_id); if not rule: return api_error("Rule not found", "NOT_FOUND", 404)`
       - Return api_success(rule.to_dict())

    4. **PUT /api/v1/rules/<int:rule_id>** (methods=['PUT'])
       - `@login_required`
       - Get rule or 404. Update fields from request.json: name, description, trigger_topic, condition (->condition_json), action (->action_json), rate_limit_per_min, schedule_cron, enabled.
       - Only update fields present in request.json.
       - sa.session.commit()
       - rule_changed.send('api', action='updated', rule_id=rule.id)
       - Return api_success(rule.to_dict())

    5. **DELETE /api/v1/rules/<int:rule_id>** (methods=['DELETE'])
       - `@login_required`
       - Get rule or 404. sa.session.delete(rule); sa.session.commit()
       - rule_changed.send('api', action='deleted', rule_id=rule_id)
       - Return api_success({"message": f"Rule {rule_id} deleted"})

    6. **POST /api/v1/rules/<int:rule_id>/enable**
       - `@login_required`
       - Get rule or 404. rule.enabled = True; sa.session.commit()
       - rule_changed.send('api', action='updated', rule_id=rule.id)
       - Return api_success(rule.to_dict())

    7. **POST /api/v1/rules/<int:rule_id>/disable**
       - `@login_required`
       - Get rule or 404. rule.enabled = False; sa.session.commit()
       - rule_changed.send('api', action='updated', rule_id=rule.id)
       - Return api_success(rule.to_dict())

    8. **POST /api/v1/rules/<int:rule_id>/test**
       - `@login_required`
       - Get rule or 404. Get request.json: topic (required), payload (required, string).
       - Parse payload as JSON if possible, else None.
       - Check topic matching: use MQTTMatcher with single rule, check if topic matches trigger_topic. Import from paho.mqtt.matcher.
       - Check condition: evaluate(json.loads(rule.condition_json), payload_dict)
       - Return api_success({"match": topic_matches and condition_matches, "topic_match": topic_matches, "condition_match": condition_matches, "actions": [json.loads(rule.action_json)] if matched else []})
       - Catch ConditionError: return api_error with 400.
