  <behavior>
    - evaluate({"path": "temperature", "op": "gt", "value": 30}, {"temperature": 35}) returns True
    - evaluate({"path": "temperature", "op": "gt", "value": 30}, {"temperature": 25}) returns False
    - evaluate({"path": "sensors.outdoor.temp", "op": "eq", "value": 22}, {"sensors": {"outdoor": {"temp": 22}}}) returns True
    - evaluate({"all": [{"path": "temp", "op": "gt", "value": 20}, {"path": "temp", "op": "lt", "value": 40}]}, {"temp": 30}) returns True
    - evaluate({"any": [{"path": "status", "op": "eq", "value": "on"}, {"path": "status", "op": "eq", "value": "active"}]}, {"status": "active"}) returns True
    - evaluate({"path": "name", "op": "contains", "value": "sensor"}, {"name": "temp_sensor_1"}) returns True
    - evaluate({"path": "name", "op": "not_contains", "value": "xyz"}, {"name": "abc"}) returns True
    - evaluate({"path": "topic", "op": "regex", "value": "^sensor_\\d+"}, {"topic": "sensor_42"}) returns True
    - evaluate({"path": "temp", "op": "exists"}, {"temp": 0}) returns True
    - evaluate({"path": "missing", "op": "exists"}, {"temp": 0}) returns False
    - evaluate({"path": "missing", "op": "not_exists"}, {"temp": 0}) returns True
    - evaluate({"path": "temp", "op": "gt", "value": 30}, None) returns False (non-JSON payload)
    - evaluate({"path": "temp", "op": "gt", "value": 30}, {"temp": "35"}) returns True (numeric coercion)
    - evaluate({}, {"temp": 30}) returns True (empty condition = always match)
    - evaluate({"path": "x", "op": "unknown_op", "value": 1}, {"x": 1}) raises ConditionError
  </behavior>
  <action>
    1. Create `mqttui/rules/evaluator.py` with:
       - `class ConditionError(Exception): pass`
       - `def _get_path(data, path)` — splits on '.', walks dict, raises KeyError on missing.
       - `def _coerce_numeric(actual, expected)` — if expected is int/float and actual is str, try float(actual). Return actual unchanged on failure.
       - `def evaluate(condition, payload)` — the pure function:
         - If condition is empty dict or None, return True (no condition = always match).
         - If 'all' key: return all(evaluate(c, payload) for c in condition['all'])
         - If 'any' key: return any(evaluate(c, payload) for c in condition['any'])
         - Extract path, op, value from condition.
         - For 'exists': try _get_path, return True/False.
         - For 'not_exists': inverse of exists.
         - For all other ops: get actual via _get_path, return False on KeyError/TypeError.
         - Apply _coerce_numeric(actual, value) before comparison ops (gt, lt, gte, lte).
         - Operators: eq (==), ne (!=), gt (>), lt (<), gte (>=), lte (<=), contains (value in str(actual)), not_contains (value not in str(actual)), regex (re.search(str(value), str(actual))).
         - Unknown op: raise ConditionError(f"Unknown operator: {op}")

    2. Create `tests/test_rules_evaluator.py` with test functions covering every behavior listed above. Use `pytest.raises(ConditionError)` for the unknown operator test. Import directly: `from mqttui.rules.evaluator import evaluate, ConditionError`.

    Write tests FIRST (RED), then implement evaluator (GREEN).
  </action>
