  <action>
    Modify `mqttui/rules/engine.py` to add scheduler and hot-reload:

    1. Add imports at top:
       ```python
       from apscheduler.schedulers.gevent import GeventScheduler
       from apscheduler.jobstores.sqlalchemy import SQLAlchemyJobStore
       from apscheduler.triggers.cron import CronTrigger
       from mqttui.events import rule_changed
       ```

    2. Add module-level singleton and scheduled job function:
       ```python
       _engine = None  # Module-level singleton reference

       def _fire_scheduled_rule(app, rule_id):
           """Module-level function for APScheduler pickle compatibility."""
           with app.app_context():
               if _engine:
                   _engine.fire_scheduled_rule(rule_id)
       ```

    3. Add to RuleEngine.__init__:
       - self._scheduler = None
       - self._app = app

    4. Add method `init_scheduler(self)`:
       - Build jobstores using self._app.config['SQLALCHEMY_DATABASE_URI']
       - `self._scheduler = GeventScheduler(jobstores={'default': SQLAlchemyJobStore(url=uri)}, job_defaults={'misfire_grace_time': 30, 'max_instances': 1, 'coalesce': True})`
       - `self._scheduler.start()`

    5. Add method `fire_scheduled_rule(self, rule_id)`:
       - Get rule from self._rules cache (it must be loaded).
       - If not found or not enabled, return.
       - Build action_dict from json.loads(rule.action_json).
       - Build context: rule_id, rule_name, topic='__scheduled__', payload=''.
       - Check rate limit. If ok: execute_action(action_dict, context). Fire rule_fired signal. Update fire_count and last_fired.

    6. Add method `sync_scheduled_jobs(self)`:
       - If self._scheduler is None, return.
       - Get all current job ids from scheduler: `existing_jobs = {job.id for job in self._scheduler.get_jobs()}`
       - For each rule in self._rules.values():
         - If rule.schedule_cron is not None and rule.schedule_cron != '':
           - job_id = f'rule_{rule.id}'
           - `self._scheduler.add_job(_fire_scheduled_rule, trigger=CronTrigger.from_crontab(rule.schedule_cron), args=[self._app, rule.id], id=job_id, replace_existing=True)`
           - Remove job_id from existing_jobs set.
         - Else: if f'rule_{rule.id}' in existing_jobs, remove the job.
       - For remaining job_ids in existing_jobs that start with 'rule_': `self._scheduler.remove_job(job_id)` (cleanup deleted rules).

    7. Modify `reload_cache(self)` to call `self.sync_scheduled_jobs()` at the end.

    8. Add method `_on_rule_changed(self, sender, **kwargs)`:
       - Call self.reload_cache() (within app_context if needed).

    9. Modify `connect(self)` to also:
       - `rule_changed.connect(self._on_rule_changed)`
       - Call `self.init_scheduler()` if not already initialized.

    10. Add module-level function `def get_engine(): return _engine`

    11. In `connect(self)`: set `global _engine; _engine = self`
